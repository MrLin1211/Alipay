# Merchant

商家后台，用于商家注册登录、管理商品、配置支付参数、查看支付订单和商品订单。

## 启动

```bash
cd merchant
npm run dev
```

默认访问：

```text
http://127.0.0.1:5174
```

## 功能

- 订单列表
- 按订单号查询
- 按支付状态筛选
- 查看平台原始响应
- 查看支付通知内容
- 查看支付配置
- 查看回调通知参数、验签结果和更新时间
- 商品管理
- 商品订单管理

## 后端接口

默认调用：

```text
http://localhost:8081
```

页面顶部可以修改后端地址。
